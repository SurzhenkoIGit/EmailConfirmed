# Проект EmailConfirmed

`EmailConfirmed` — это веб-приложение, разработанное на платформе ASP.NET Core MVC. Оно представляет собой многофункциональный сайт с системой управления пользователями, чатом в реальном времени и интегрированным чат-ботом.

## Основные возможности

*   **Аутентификация и авторизация:**
    *   Регистрация пользователей с обязательным подтверждением по электронной почте.
    *   Вход в систему с поддержкой двухфакторной аутентификации (2FA).
    *   Функционал восстановления забытого пароля.
    *   Разграничение доступа на основе ролей (например, "Администратор").

*   **Управление клиентами:**
    *   Полный набор CRUD-операций (создание, чтение, обновление, удаление) для управления сущностями "клиентов".

*   **Чат в реальном времени:**
    *   Интерактивный чат между пользователями, построенный с использованием технологии SignalR.
    *   История сообщений сохраняется в базе данных.

*   **ИИ-ассистент (Чат-бот):**
    *   Заранее записанные шаблоны для предоставления ответов в отдельном интерфейсе чат-бота. Также есть версия со встроенной LLM-модели (экспериментально).

## Технологический стек

*   **Бэкенд:**
    *   .NET / ASP.NET Core MVC
    *   Entity Framework Core (для взаимодействия с базой данных)
    *   ASP.NET Core Identity (для управления пользователями и ролями)
    *   SignalR (для функционала реального времени)
    *   LLamaSharp (для интеграции с моделью LLaMA)

*   **Фронтенд:**
    *   Razor Views
    *   JavaScript, jQuery
    *   Bootstrap, Tailwind CSS
    *   FontAwesome

*   **База данных:**
    *   Microsoft SQL Server (используется LocalDB в строке подключения по умолчанию)

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd EmailConfirmed
    ```

2.  **Настройте базу данных:**
    *   Строка подключения по умолчанию находится в `EmailConfirmed/Program.cs` и использует SQL Server LocalDB:
        ```csharp
        string conStr = "Server=(localdb)\\mssqllocaldb;Database=usersdb46;Trusted_Connection=True;MultipleActiveResultSets=true";
        ```
    *   Убедитесь, что у вас установлен SQL Server LocalDB, или измените строку подключения на свою в `appsettings.json`.
    *   Примените миграции для создания схемы базы данных:
    ```bash
    dotnet ef database update --project EmailConfirmed
    ```

3.  **Запустите приложение:**
    ```bash
    dotnet run --project EmailConfirmed
    ```

## Структура проекта

*   `/Controllers` - Контроллеры, обрабатывающие входящие HTTP-запросы.
*   `/Views` - Представления (UI), написанные с использованием Razor.
*   `/Models` - Модели данных, ViewModels и классы бизнес-логики.
*   `/Data` - Контекст базы данных (`ApplicationContext`) и миграции Entity Framework Core.
*   `/Hubs` - Хабы SignalR для коммуникации в реальном времени.
*   `/Services` - Сервисные классы, инкапсулирующие бизнес-логику (например, `EmailService`, `ClientService`).
*   `/wwwroot` - Статические ассеты: CSS, JavaScript, изображения и сторонние библиотеки.
